# NEON PROMOTER — public website only

This repository is intended to host the public landing page and privacy policy for the NEON PROMOTER Pinterest integration project. The private desktop application, credentials and other NEON POD STUDIO source code are **not** included.

## Before submitting to Pinterest

1. In `privacy.html`, replace the placeholder in the Contact section with a real public contact method, such as a dedicated email or a public GitHub Issues link.
2. Review every policy statement for accuracy before using the site in an API application. Update it when the desktop integration actually ships.
3. Enable GitHub Pages under **Settings → Pages → Deploy from a branch → main / (root)**.

Your website will be `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/` and privacy policy `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/privacy.html` (replace placeholders with your real account/repository values).
