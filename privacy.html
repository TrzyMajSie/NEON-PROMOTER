Privacy Policy — NEON PROMOTER

Effective date: October 14, 2026

NEON PROMOTER is a private desktop software project currently under development to help its owner manage organic Pinterest content linking to original TeePublic products.

Data accessed

When Pinterest integration is enabled, the application is intended to access only the Pinterest account data authorized by the user, such as boards, Pins and related analytics. It may handle Pin titles, descriptions, product images and product links supplied by the user.

Purpose of use

Authorized data will be used for preparing and publishing Pins to the user's own boards, avoiding duplicate submissions and displaying performance information.

Storage and sharing

The planned desktop application is intended to store its configuration and authorization credentials locally on the user's computer. It will communicate with Pinterest's official API as needed to provide its functions. It is not intended to sell personal information or share Pinterest account data with advertisers. Implementation details will be reviewed and this policy updated before public API publishing is enabled.

Control and deletion

The user can revoke access through Pinterest account settings. Locally stored application data may be removed by deleting the application configuration. Deletion procedures will be documented when the application is released.

Children

This application is not designed for children.
